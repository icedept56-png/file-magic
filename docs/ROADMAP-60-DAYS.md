## ১. মূলনীতি (প্রতিদিনের কাজ এগুলো মেনে চলবে)

1. **সমস্যা আগে, ফিচার পরে** — প্রতিটি দিনের কাজ একটি নামধারী ব্যবহারকারীর ব্যথা শুধরাবে
2. **প্রাইভেসি অবিচ্ছেদ্য** — ফাইল প্রসেসিং চিরকাল ক্লায়েন্ট-সাইড; শুধু অ্যাকাউন্ট/মিটারিং সার্ভারে
3. **কোয়ালিটি > পরিমাণ** — যাচাই ছাড়া দিন শেষ হবে না: lint 0 + tsc পরিষ্কার + ব্রাউজার E2E (ডেস্কটপ+মোবাইল, bn+en)
4. **বাংলা-ফার্স্ট** — প্রতিটি স্ক্রিন bn/en, বাংলা সংখ্যা, বাংলা টেক্সট সব আউটপুট ফরম্যাটে নিরাপদ
5. **কোনো রিগ্রেশন নয়** — নতুন কাজ পুরনো কাজ ভাঙবে না (প্রতি ফেজ-গেটে সম্পূর্ণ regression)
6. **শেখা → লগ** — প্রতিদিন worklog.md-তে Task ID এন্ট্রি: কী শিখলাম, কী সিদ্ধান্ত নিলাম

## ২. দৈনিক রিদম (প্রতিদিন একই চক্র)

# ফেজ ১ (Day 1–12): প্রোডাক্ট কোর — "যেকোনো ফাইল, নিখুঁত ফলাফল"

*বিশ্লেষণ: বিজনেসের আগে প্রোডাক্ট। ব্যবহারকারী ফিরে আসবে শুধু তখনই যখন ফলাফল নিখুঁত। এই ফেজে বাংলাভাষী মার্কেটের সবচেয়ে বড় ৩ ব্যথা বন্ধ হবে: স্ক্যান, ব্যাচ, এবং নির্ভুলতা।*

| দিন | ডেলিভারেবল | ব্যবহারকারীর সমস্যা |
|---|---|---|
| **1 (আজ)** | **ডকুমেন্ট স্ক্যানার** — ফোনের ছবি → পরিষ্কার স্ক্যান (অটো-লেভেল, ধূসর/সাদা-কালো/ম্যাজিক প্রিসেট, অটো-থ্রেশহোল্ড, মাল্টি-পেজ PDF/JPG, রিঅর্ডার) | NID/দলিল/ফর্মের ছবি অন্ধকার-ঝাপসা লাগে; CamScanner-এর মতো অ্যাপ দরকার |
| 2 | **OCR (বাংলা+ইংরেজি)** — স্ক্যান করা ছবি/PDF → এডিটেবল টেক্সট; স্ক্যানারের সাথে যুক্ত | স্ক্যান করা কাগজের লেখা কপি-পেস্ট করা যায় না |
| 3 | **ব্যাচ মোড** — একসাথে অনেক ফাইল → একই কাজ → ZIP ডাউনলোড | ২০টা ছবি কম্প্রেস করতে ২০ বার করতে হয় |
| 4 | **PDF পেজ ম্যানেজার ২.০** — ভিজ্যুয়াল থাম্বনেইল গ্রিড, ড্র্যাগ-রিঅর্ডার, নির্বাচিত পেজ এক্সট্র্যাক্ট, ব্ল্যাঙ্ক/ছবি পেজ যোগ | PDF-এর পেজ সাজাতে দেখতে দেখতে সাজানোর সুবিধা নেই |
| 5 | **কম্প্রেশন ২.০** — লাইভ কোয়ালিটি স্লাইডার + সাইজ প্রেডিকশন + before/after প্রিভিউ | কত ছোট হবে জানি না, কোয়ালিটি নষ্ট হয়ে যায় |
| 6 | **Word এডিটর (docx)** — লিখুন/এডিট করুন, বাংলা ফন্ট নিরাপদ, PDF/docx এক্সপোর্ট | docx বানাতে MS Word লাগে |
| 7 | **ইউনিফাইড আন্ডো/রিডু** — সব এডিটরে এক সিস্টেম (Ctrl+Z) | ভুলে এক ক্লিকে কাজ নষ্ট |
| 8 | **কীবোর্ড শর্টকাট + অ্যাক্সেসিবিলিটি অডিট** — সব ফ্লো কীবোর্ডে, ARIA সম্পূর্ণ | পাওয়ার ইউজার ও প্রতিবন্ধী ব্যবহারকারী বাদ পড়ে |
| 9 | **বড় ফাইল পারফরম্যান্স** — Web Worker, স্ট্রিমিং, প্রোগ্রেস, মেমোরি নিয়ন্ত্রণ | ৫০MB PDF-এ ব্রাউজার আটকে যায় |
| 10 | **ফরম্যাট কভারেজ ব্লিটজ** — HEIC, WebP→JPG ব্রাউজারে, RTF/ODT পড়া, PPTX টেক্সট এক্সট্র্যাক্ট | "এই ফরম্যাট কেন কাজ করে না?" |
| 11 | **আউটপুট কোয়ালিটি অ্যাসিউরেন্স** — ফাইল ভ্যালিডেটর, edge-case কর্পাস, করাপ্ট ফাইল বান্ধব এরর | আউটপুট ফাইল অন্য সফটওয়্যারে না খুললে বিশ্বাস যায় |
| 12 | **ফেজ ১ গেট** — সম্পূর্ণ E2E regression স্যুট, সব বাগ ফিক্স, ফেজ ২ পরিকল্পনা রিফ্রেশ | — |
